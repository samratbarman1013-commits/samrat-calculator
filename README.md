# Calculator

A fast, offline-capable calculator web app (PWA).

**Live app:** https://samratbarman1013-commits.github.io/samrat-calculator/

## Features
- Basic arithmetic (+, -, x, /), percent, sign toggle
- Calculation history (tap a past result to reuse it)
- Works fully offline after first load (service worker)
- Installs to your phone's home screen like a native app

## Files
- `index.html` - the app
- `manifest.webmanifest` - PWA install metadata
- `sw.js` - offline caching service worker
- `icons/` - app icons
